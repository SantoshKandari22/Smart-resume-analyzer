# Smart Resume Analyzer

Smart Resume Analyzer is a web-based project developed to simplify resume screening and candidate evaluation. The system helps in analyzing resumes, managing candidate information, and improving the recruitment process through a clean and responsive interface.

The project is designed with a focus on usability, performance, and easy management for both users and administrators.

---

## Features

- Resume upload and management
- Candidate profile analysis
- Skill-based evaluation
- Admin dashboard
- Responsive user interface
- Secure login system
- Easy navigation and clean design

---

## Technologies Used

- PHP
- Bootstrap
- HTML5
- CSS3
- JavaScript
- MySQL

---

## Project Installation

### Step 1
Download or clone the repository into your system.

```bash
git clone https://github.com/SantoshKandari22/smart-resume-analyzer.git
```

### Step 2
Move the project folder into the `htdocs` directory of XAMPP.

### Step 3
Open phpMyAdmin and import the provided database file.

### Step 4
Start Apache and MySQL from the XAMPP Control Panel.

### Step 5
Run the project in your browser:

```txt
http://localhost/smart-resume-analyzer
```
